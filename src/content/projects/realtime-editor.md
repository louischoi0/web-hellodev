## Problem

동시 편집자가 20명을 넘으면 변경 사항이 서로 덮어써졌고, 사용자는 저장 버튼을 여러 번 누르는 방식으로 우회하고 있었습니다.

## Approach

- 서버 중심 OT를 CRDT 기반 동기화로 교체했습니다.
- 문서 단위로 WebSocket 연결을 샤딩하고, Redis Streams로 노드 간 변경을 전파했습니다.
- 지연 시간 p95를 대시보드로 공개해 팀 전체의 목표로 만들었습니다.

## Result

- 충돌률 3.2% → 0.1% 미만
- 동기화 지연 p95 420ms → 85ms
- 편집기 관련 고객 문의 월 140건 → 12건
