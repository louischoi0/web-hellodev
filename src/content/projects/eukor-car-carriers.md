## Scope

2022년 5월부터 2023년 10월까지 Eukor Car Carriers의 DBA로 Azure SQL Server 운영 데이터베이스를 관리했습니다.

## Work

- **설계 및 튜닝.** 테이블 관계와 인덱스를 설계·효율화하고, 쿼리를 튜닝 및 컨버팅했습니다.
- **대용량 데이터 통합.** 10TB 이상 운영 데이터의 변환 · 통합 배치 스크립트를 개발하고 수행 · 모니터링했습니다.
- **운영 자동화.** Azure SQL Job Agent 기반으로 데이터베이스 운영 모니터링을 자동화했습니다.
- **Data Lake 파이프라인.** Azure Synapse Analytics로 RDBMS → Data Lake 파이프라인을 구축하고 효율화했습니다.
